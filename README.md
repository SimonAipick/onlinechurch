# 온라인교회

함께 예배하고, 찬송을 듣고, 기도하고, 말씀을 읽는 3D 온라인 예배당입니다.

- 찬송가 51곡과 찬양·명곡 12곡을 실제 그랜드피아노 녹음으로 연주해요 (모두 저작권이 끝난 곡).
- 성경 전체(개역한글)와 유명한 구절 48개를 읽을 수 있어요.
- 기도하기, 기도 촛불 켜기, 축복 인사하기, 예배당 사진 찍기를 할 수 있어요.
- 같은 예배실에 들어온 사람끼리 실시간으로 서로 보여요 (별명·자리·기도 중 여부·축복 인사·촛불만 주고받아요).

## 자료 출처
- 성경 본문: 개역한글판(1961, 저작재산권 보호기간 만료)
- 찬송·찬양 악보: Open Hymnal Project, John Chambers ABC 모음
- 기도 메달 그림: 알브레히트 뒤러, 「기도하는 손」(1508), 퍼블릭 도메인
- 피아노 음원: Salamander Grand Piano V3 — Alexander Holm, CC BY 3.0 (Tone.js audio 저장소의 mp3 버전)
- 3D 렌더링: three.js r128
- 실시간 연결: 무료 공개 MQTT 중계 서버(broker.emqx.io), mqtt.js 4.3.7
